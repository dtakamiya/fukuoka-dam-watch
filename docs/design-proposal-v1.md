# デザイン提案 v1 — 現状の所見と改善方針

対象: 公開サイト <https://dtakamiya.github.io/fukuoka-dam-watch/>
成果物: デザインキャンバス（Artifact） <https://claude.ai/code/artifact/9f69a26d-5ee2-4468-8b02-dfb7608cddbf>
状態: **提案のみ**。`index.html` / `assets/*` への反映・PR 化はしていない。数値はサンプルデータ。

## 既存実装の所見（現状 UI の課題）

1. **貯水率が数値の羅列**。カードは「73.5% ▲0.2pt」のテキストのみで、満量に対する水位が視覚的に瞬時に読めない。9枚を見比べる手がかりが色帯（`border-left` 5px）だけ。
2. **前時点比の情報が3系統に重複**。数値横の方向グリフ + カード下部のチップ2つ（貯水量・貯水率） + サマリの `summary-delta`。同じことを3回言っていて視線が散り、カードの縦が伸びる。
3. **合計サマリの密度が低い**。大きな白カードに `56.3%` が1つだけ。9ダムのうち何ダムが注意以下か、直近の傾向、といった「まず読むべき要約」がない。
4. **しきい値が3段階で粗い**。平常 ≥60 / 注意 30–60 / 渇水 <30。「注意」が 30pt 幅と広く、状況の温度差が出ない。配色は既存 CSS 変数由来だが平常＝緑・注意＝橙・渇水＝赤の3色のみ。
5. **推移グラフが文脈に乏しい**。30日でほぼ横ばいの1本線が広い余白に置かれ、「いまの水準がどの段階か」がグラフ上で分からない。しきい値のライン／ゾーンがない。
6. **モバイルがカード縦積みで長い**。合計サマリ＋9カードで相当スクロールする。片手でざっと現状を把握する導線がない。タイポ・余白のリズムは全幅で均一。

## 改善提案（現状 → 改善）

| # | 観点 | 現状 | 改善 |
|---|------|------|------|
| 1 | 貯水率の可視化 | 数値テキストのみ | **円形リングゲージ**（貯水率＝充填率）＋中央に数値。9枚を面で比較できる |
| 2 | 情報階層 | ヘッダー青ベタ塗りが最も目立つ | ヘッダーを細く、**合計貯水率リング＋状態ラベル**を最上位に。次に9ダムグリッド、最後にグラフ導線 |
| 3 | 合計サマリ | 数値1つ | リング＋**内訳セグメントバー**（安全6／注意2／警戒1／危険0）＋30日スパークライン＋前時点比を1行に集約 |
| 4 | 前時点比 | 3系統重複 | **1系統に統合**。数値の下に「前時点比 ▲+0.2pt」だけ。下部チップと重複グリフを廃止 |
| 5 | しきい値の段階 | 3段階（≥60 / 30–60 / <30） | **4段階**：安全 ≥70 ／ 注意 50–70 ／ 警戒 30–50 ／ 危険 <30。「注意」帯を割って温度差を出す |
| 6 | しきい値の配色 | 緑・橙・赤 | 緑→金→橙→赤の**明度・色相を段階変化**させ色覚に依らず順序が伝わる。色＋ラベル＋リング形状の三重表現 |
| 7 | カードのレイアウト | `auto-fill minmax(210px)` で列数可変 | **3列固定グリッド**。リング左＋数値・容量・前時点比を右に。左色帯は 4px に整理 |
| 8 | 推移グラフ | 素の折れ線 | 背景に**しきい値ゾーンの帯**（安全/注意/警戒/危険）、y軸 0–100 固定、平常ライン 60%、末尾に現在値マーカー |
| 9 | モバイル最適化 | 9カード縦積み | 先頭に**コンパクト合計サマリ**（リング＋内訳バー）→ 2列タイル（リング＋率＋前時点比）で 9ダムを一望 → グラフへの CTA。スクロール量を圧縮 |
| 10 | ダークモード | 非対応 | `prefers-color-scheme: dark` 対応。レイアウト共通・トークンのみ差し替え。水色アクセントは明度を上げて維持 |
| 11 | タイポと余白 | 行間 1.7 均一、見出しは下線のみ | 見出し 800 / 数値 tabular-nums / セクション区切りを段階化。カード内は 12–15px の階層 |

## 実装マッピング（反映時の勘所・未確定）

- CSS 変数 `--normal / --caution / --drought` → `--safe / --watch / --alert / --crit` の4系統へ。各 `*-bg` も同様。
- `app.js` の `RATE_NORMAL_MIN(60) / RATE_CAUTION_MIN(30)` に `RATE_SAFE_MIN(70) / RATE_ALERT_MIN(30)` を加え、`rateClass` / `rateLabel` を4分岐に。
- リングは SVG（`stroke-dasharray` = 円周 × 率）。Chart.js は不要、依存は増えない。
- 内訳セグメントバーは `latest.dams` を4区分に集計するだけ。
- グラフのしきい値ゾーンは Chart.js の `annotation` 相当（背景 `<rect>` かプラグイン）。プラグイン追加を避けるなら y スケール固定＋グリッド着色でも可。
- **境界値 30 / 50 / 70 は仮値**。福岡市の取水制限運用（おおむね10%刻み）を参照したたたき台で、正式なダム別基準が入手でき次第ダム個別に上書きする。
- 前時点比の統合表示は、色覚非依存のため形状アイコン＋`aria-label`（既存 `makeIndicator` の文言）を維持する。
